# سوق تك

واجهة متجر إلكتروني عربية مبنية باستخدام React وVite، تعرض منتجات الإلكترونيات من [DummyJSON Products API](https://dummyjson.com/docs/products).

## التشغيل

```sh
npm install
npm run dev
```

## مصدر المنتجات

يحمّل المتجر بيانات الهواتف واللابتوبات والأجهزة اللوحية والإكسسوارات مباشرة من:

`https://dummyjson.com/products`

تُعرض الأسعار بالدولار الأمريكي كما يوفّرها المصدر. يتطلب تحميل الكتالوج اتصالًا بالإنترنت؛ وتظهر رسالة مع خيار إعادة المحاولة عند تعذر الوصول إلى الـAPI.
